# Contributing

## Where to participate

- Use an **Issue** for a concrete bug, broken link, leaked private datum, malformed metadata, or reproducibility failure in repository material.
- Use **Discussions** for replication reports, critiques and falsification, research ideas, collaboration proposals, or applications.
- Use a pull request for a bounded correction with evidence.

## Minimum report

State the Research Note ID, the exact commit tested, operating system and relevant versions, command run, expected result, observed result, and any changed inputs. A failed replication is useful even when its cause is unknown.

## Integrity rules

- Do not rewrite or delete failed sealed predictions.
- Separate a correction from the original artifact and record the reason.
- Do not strengthen a claim beyond its stated evidence class.
- Preserve `UNKNOWN` until new evidence resolves it.
- Do not submit personal data, credentials, machine-specific paths, or private-repository references.
