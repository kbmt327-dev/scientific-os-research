# Licensing status

This repository intentionally does not apply one blanket license to materials with different legal and scientific roles.

| Material | Current status |
|---|---|
| Quartz site generator and retained upstream files | MIT License; see `LICENSE.txt` and upstream notices. |
| Original research notes | License decision pending. No permission beyond viewing and quoting as allowed by applicable law is granted yet. |
| Original reproduction code | License decision pending. No broad reuse license is granted yet. |
| Generated or bundled datasets and artifacts | Dataset-specific review pending. Presence in the repository does not imply unrestricted reuse. |

This conservative initial state avoids accidentally granting rights the maintainer may not hold. A future release may add separate licenses for text, software, and datasets after provenance review. Until then, you may still report replications, bugs, and critiques by linking to the relevant public material.
