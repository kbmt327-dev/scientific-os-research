Choose the action that matches the evidence you can add.

<div class="contribute-grid">
  <a href="/scientific-os-research/en/contribute/reproduce/"><b>Reproduce</b><span>Run the same public package and report what happened.</span></a>
  <a href="/scientific-os-research/en/contribute/audit/"><b>Challenge</b><span>Report a defect, failed prediction, counterexample, or competing interpretation.</span></a>
  <a href="/scientific-os-research/en/contribute/audit/#extend-a-result"><b>Extend</b><span>Change one declared condition and test whether the claim survives.</span></a>
  <a href="/scientific-os-research/en/contribute/collaborate/"><b>Collaborate</b><span>Bring a trace, instrument, domain boundary, or joint study.</span></a>
</div>

Start with the Research Note ID and tested commit. Keep observations separate from interpretations. Never upload confidential or personal data to a public thread.
