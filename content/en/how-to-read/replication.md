An independent replication is work performed outside the original research process using a declared version of the note and artifacts. A rerun by the same process is a reproducibility check, not independent replication.

The `scripts/reproduce.py --quick` path shown in each note is also a bounded check of public artifacts, not an independent replication.

Each note starts with independent replications, failed replications, confirmed bugs, and open critiques at zero. All of them are still zero. Reports should include the tested commit, environment, command, inputs, observed output, and deviations from the published procedure.
