追加できる証拠に合う入口を選んでください。

<div class="contribute-grid">
  <a href="/ja/contribute/reproduce"><b>再現する</b><span>同じ公開パッケージを実行し、起きたことを報告する。</span></a>
  <a href="/ja/contribute/audit"><b>反証する</b><span>欠陥、外れた予測、反例、対立する解釈を示す。</span></a>
  <a href="/ja/contribute/audit#結果を拡張する"><b>拡張する</b><span>条件を一つだけ明示して変え、主張が残るか検査する。</span></a>
  <a href="/ja/contribute/collaborate"><b>共同研究する</b><span>トレース、測定機器、分野の境界、共同研究を持ち寄る。</span></a>
</div>

研究のIDと検査したコミットから始め、観測と解釈を分けて書いてください。機密情報や個人データを公開スレッドへ置かないでください。
