# Printed Hill procedure audits

This package contains the public transcription of Hill's printed 1929 C3/C4 transformations and projects EP-0216, EP-0217, EP-0218, and EP-0230. The bounded verifier checks the transcription dimensions and recorded summary only.

Run from the repository root:

    python reproduction/kryptos-k4-hill-printed/verify_hill_printed.py

This command does not rerun the K4 searches or shuffle nulls. The registered lists cover the printed transformations and specified encodings, block conventions, and phases. They do not cover every Hill matrix, every possible block boundary, or unspecified transformations.

No K4 plaintext is published. New plaintext characters: 0. Independent replications: 0.
