# Printed procedure audits

This package retains the existing lightweight transformations and projects EP-0231, EP-0232, EP-0233, EP-0234, and EP-0237. The public record includes finite searches of transcribed historical procedures and registered masks. EP-0234's free-square diagnostic is kept distinct from the other primary columns.

Run from the repository root:

    python reproduction/kryptos-k4-printed-procedures/verify_printed_procedures.py

The verifier checks public input dimensions, the transcribed Gaines table size, result-record counts, and the separation of EP-0234's diagnostic. It does not rerun candidate searches or shuffle nulls.

No K4 plaintext is published. New plaintext characters: 0. Independent replications: 0. The listed outcomes do not exclude untested historical procedures or parameterizations.
